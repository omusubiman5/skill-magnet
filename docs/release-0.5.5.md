# Skill Magnet 0.5.5 リリース報告

## 結果

フォルダーを選択したExplorer／Finderの右クリックから、選択フォルダーを選び直さずにスキル登録できるようにした。

## 変更内容

- `Skill Magnet`メニューへ`このフォルダーのスキルを登録`を追加した。
- 右クリックしたフォルダーの絶対パスをLibrary Managerへ渡し、起動時に構成を検証して登録する。
- `Library Manager`は一覧・更新・削除・公開用として分離し、開いただけでは登録しない。
- `SKILL.md`がない、構成が壊れている、重複が不整合な場合は登録せずエラー表示する。
- 登録済みの同一内容はエラーにせず、登録済みであることを表示する。

## 受入条件

- 選択フォルダーのパスがネイティブメニューからCLI、GUI、登録処理まで保持される。
- 登録専用項目と管理項目がメニュー上で区別できる。
- Windows modern context menuの実機状態が設定と一致する。
- Windows／macOS CIと全自動テストがPASSする。
